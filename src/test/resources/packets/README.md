# Sample packets

Packets a caller sends to the shared services, and the result it gets back. Made-up data only.
Tests send these packets, with the FedEx client replaced by the replies in `../fedex/`.

| File | Use |
| --- | --- |
| `label-request-one-box.json` | Label request, one box, with dimensions |
| `label-request-two-boxes.json` | Label request, two boxes |
| `label-result-one-box.json` | The result for one box, as the caller receives it |
| `void-request.json` | Void request |
| `address-check-request.json` | Address check request |
